# Numen: Knightfall

**Project Title:** Integration of a Local Large Language Model Framework for Real-Time NPC Dialogue Generation and Behavioural Simulation in Interactive Game Worlds

**Module:** COMP3000 Computing Project (40 credits)
**Programme:** BSc (Hons) Computer Science (AI)
**Institution:** University of Plymouth, School of Engineering, Computing and Mathematics
**Academic Year:** 2025–2026
**Supervisor:** Dr Vasilios Kelefouras

## Project Vision

Numen: Knightfall is a vertical-slice tech demo investigating whether knowledge-gated, LLM-driven NPC dialogue produces a more immersive and believable player experience than traditional pre-authored dialogue trees. The artefact is a small Unreal Engine 5 environment set at St. Damson''s, a knight training institute, populated by NPCs at three different ranks (Initiate, Squire, Knight-Instructor) whose dialogue is generated by a local LLM through a knowledge-gated middleware pipeline.

The research contribution is the knowledge-gating architecture itself — a reusable pattern for constraining what an LLM-driven NPC can know based on social role — not the game it is demonstrated in.

## Hypotheses

- **H1 — Believability.** LLM-driven NPCs are rated more immersive than dialogue-tree NPCs (Likert questionnaire).
- **H2 — Knowledge boundaries.** Gating prevents out-of-tier information leakage in ≥95% of adversarial queries.
- **H3 — Distinctiveness.** Blind-test participants identify NPC social class from transcripts at >60% accuracy.
- **H4 — Latency.** Median local-inference response time under 2 seconds with a quantised 7B model.

## Architecture

Unreal Engine 5 → HTTP/JSON → Python FastAPI middleware → local llama.cpp inference server → response validation → back to UE5.
